# Gold4Cast Roadmap

[نقشه راه فارسی](ROADMAP_FA.md)

## v1.0 — Current
- XGBoost quantile forecasting
- Gold18 + USD/IRR + XAU/USD
- 3M / 6M / 12M horizons
- Persian mobile HTML
- scenario visualization
- permanent live scorecard
- dense walk-forward validation

## v1.1
- pluggable data-provider interface
- schema validation and stale-data warnings
- automated tests
- exportable JSON API
- English HTML UI

## v1.2
- post-hoc quantile calibration
- model-drift monitoring
- rolling live-performance dashboard
- block-bootstrap confidence intervals

## v2.0 research candidates
- rigorously benchmarked alternatives to XGBoost
- covariate-aware foundation-model evaluation
- regime-aware evaluation
- optional server/API deployment
- reproducible Docker environment

A candidate reaches a stable release only if it improves reproducible out-of-sample evidence, not because it is newer or more complex.
