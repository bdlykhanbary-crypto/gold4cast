# Gold4Cast v1.0.2

## English

This governance/documentation release records the model-selection work already
completed and prepares the public repository for structured external
contributions.

- documents TimesFM-3, Chronos-2, Moirai-2.0 and XGBoost benchmarks;
- explains why XGBoost Quantile is the current v1.x production model;
- defines what evidence is required before proposing another model;
- establishes pull-request-based main-branch governance;
- opens the initial bilingual v1.1 development issues.

No forecasting architecture is changed in v1.0.2.

## فارسی

این نسخه برای مستندسازی و مدیریت توسعه عمومی پروژه منتشر می‌شود.

- تست‌های TimesFM-3، Chronos-2، Moirai-2.0 و XGBoost را ثبت می‌کند؛
- دلیل انتخاب XGBoost Quantile به‌عنوان مدل فعلی v1.x را توضیح می‌دهد؛
- شرایط لازم برای پیشنهاد مدل جدید را مشخص می‌کند؛
- توسعه شاخه main را بر پایه Pull Request سازمان‌دهی می‌کند؛
- Issueهای اولیه و دو‌زبانه v1.1 را ایجاد می‌کند.

در v1.0.2 معماری مدل پیش‌بینی تغییر نمی‌کند.
