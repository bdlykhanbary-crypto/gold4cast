# کارت مدل — Gold4Cast v1.0

[English version](MODEL_CARD.md)

## مدل
XGBoost Quantile Regression با objective برابر `reg:quantileerror`.

## کاربرد مناسب
پژوهش، پیش‌بینی احتمالاتی بازار، ارزیابی مدل و توسعه مهندسی/آموزشی.

## کاربرد نامناسب
هدف قیمت تضمینی، کف قیمت تضمینی، معامله‌گری خودکار بدون کنترل مستقل ریسک یا توصیه مالی شخصی.

## ورودی‌ها
- طلای ۱۸ عیار ایران
- USD/IRR
- XAU/USD

## خروجی‌ها
Q10، Q50 و Q90 برای انتهای افق‌های ۶۳، ۱۲۶ و ۲۵۲ جلسه معاملاتی.

## نکته مهم درباره نمودار HTML
مسیرهای آینده‌ای که در نمودار نمایش داده می‌شوند interpolation تصویری بین قیمت فعلی و Quantile انتهای افق هستند؛ این خطوط پیش‌بینی روزبه‌روز XGBoost نیستند.

## ریسک‌ها
تغییر رژیم بازار، داده قدیمی/خراب، شوک ارزی، رویدادهای ژئوپلیتیکی، سیاست اقتصادی، نوسان شدید طلای جهانی و خطای کالیبراسیون.
