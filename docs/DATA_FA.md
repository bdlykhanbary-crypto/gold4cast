# ورودی داده

نسخه عمومی Gold4Cast به یک ارائه‌دهنده مشخص داده وابسته نیست. هیچ دیتاست
تاریخی متعلق به سرویس شخص ثالث داخل مخزن قرار نمی‌گیرد و endpoint یک سرویس
بازار نیز در کد عمومی hard-code نشده است.

یک CSV که مجاز به استفاده از آن هستید وارد کنید:

```text
date,gold18_toman,usd_irr,xau_usd
2026-01-01,....
```

قبل از اجرا مسیر فایل را مشخص کنید:

```bash
export GOLD4CAST_DATA=/path/to/market_data.csv
python forecast_xgboost_live.py
```

برای GitHub Actions می‌توانید Secret مخزن با نام `GOLD4CAST_DATA_URL` را
روی URL یک منبع داده‌ای که اجازه استفاده از آن را دارید تنظیم کنید. Workflow
فقط برای همان اجرا CSV را دریافت می‌کند و خروجی پیش‌بینی را به‌صورت artifact
می‌سازد؛ داده بازار یا تاریخچه کارنامه را داخل مخزن commit نمی‌کند.

مسئولیت رعایت مجوز، شرایط استفاده، محدودیت درخواست و قوانین منبع داده با
کاربر است.
