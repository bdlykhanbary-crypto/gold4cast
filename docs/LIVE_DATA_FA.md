# ورودی لحظه‌ای بازار

Gold4Cast بین **داده تاریخی مورد استفاده مدل** و **Snapshot لحظه‌ای بازار** تفکیک ایجاد می‌کند.

منبع تاریخچه روزانه ممکن است در ساعات بازار هنوز ردیف امروز را ثبت نکرده باشد. در چنین وضعیتی نباید Close روز قبل به‌عنوان «قیمت فعلی» نمایش داده شود. نسخه 1.0.3 یک لایه مستقل برای Snapshot لحظه‌ای اضافه می‌کند.

## طراحی عمومی و مستقل از Data Provider

نسخه عمومی به یک سرویس مشخص وابسته نیست. کاربر دو ورودی فراهم می‌کند:

1. CSV تاریخی از طریق `GOLD4CAST_DATA`
2. CSV Snapshot لحظه‌ای از طریق `GOLD4CAST_LIVE_SNAPSHOT`

ستون‌های الزامی Snapshot:

```text
date,gold18_toman,usd_irr,xau_usd
2026-09-21,23859100,2313400,4355.49
```

ستون‌های اختیاری ساعت نرخ:

```text
gold_quote_time,usd_quote_time,xau_quote_time
13:08:34,13:08:40,13:08:34
```

## جلوگیری از گزارش Stale

وقتی `GOLD4CAST_REQUIRE_LIVE=1` باشد، اگر یکی از شرایط زیر رخ دهد ربات به‌جای نمایش گزارش قدیمی متوقف می‌شود:

- فایل Snapshot وجود نداشته باشد؛
- ستون ضروری کم باشد؛
- قیمت نامعتبر یا غیرمثبت باشد؛
- تاریخ Snapshot مطابق تاریخ امروز در `Asia/Tehran` نباشد.

بنابراین Close روز گذشته نمی‌تواند بی‌سروصدا به‌عنوان نرخ لحظه‌ای وارد گزارش شود.

## نحوه استفاده مدل

تمام تاریخچه همچنان حفظ می‌شود. Snapshot لحظه‌ای فقط آخرین مشاهده را درست قبل از اجرای XGBoost جایگزین یا اضافه می‌کند:

```text
تاریخچه Gold18 + USD/IRR + XAU/USD
                  +
Snapshot لحظه‌ای
                  ↓
          XGBoost Quantile
                  ↓
      پیش‌بینی ۳ / ۶ / ۱۲ ماهه
```

HTML مقدار دقیق سه ورودی لحظه‌ای و در صورت موجود بودن ساعت هر نرخ را نمایش می‌دهد تا قابل مقایسه و ممیزی باشد.

## GitHub Actions

برای Workflow عمومی این دو Secret را تنظیم کنید:

- `GOLD4CAST_DATA_URL`
- `GOLD4CAST_LIVE_SNAPSHOT_URL`

مسئولیت مجوز و شرایط استفاده از منبع داده با کاربر است.
