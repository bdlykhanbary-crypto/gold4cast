# Gold4Cast

[English README](README.md)

**Gold4Cast** یک پروژه متن‌باز برای پیش‌بینی احتمالاتی قیمت طلای ۱۸ عیار ایران است.

نسخه 1.0 از **XGBoost Quantile Regression** استفاده می‌کند و سه ورودی اصلی دارد:

- قیمت طلای ۱۸ عیار ایران
- دلار / ریال
- اونس جهانی طلا (XAU/USD)

پیش‌بینی در سه افق انجام می‌شود:

- **۳ ماهه** — ۶۳ جلسه معاملاتی
- **۶ ماهه** — ۱۲۶ جلسه معاملاتی
- **۱۲ ماهه** — ۲۵۲ جلسه معاملاتی

برای هر افق سه عدد ارائه می‌شود:

- **برآورد پایین (Q10)**
- **پیش‌بینی اصلی / میانه (Q50)**
- **برآورد بالا (Q90)**

Gold4Cast همچنین گزارش HTML فارسی مناسب موبایل، نمودار سناریو و «کارنامه واقعی ربات» دارد؛ یعنی پیش‌بینی‌های قبلی را ذخیره می‌کند و وقتی موعد آن‌ها برسد، با قیمت واقعی بازار مقایسه می‌کند.

## چرا متن‌باز؟

نسخه 1.0 عمداً به‌صورت متن‌باز منتشر می‌شود تا برنامه‌نویسان، پژوهشگران کمی، متخصصان داده و افراد حرفه‌ای بتوانند:

- کد را بررسی و ممیزی کنند،
- بک‌تست را بازتولید کنند،
- منابع داده قانونی و معتبر اضافه کنند،
- کالیبراسیون مدل را بهتر کنند،
- مدل‌های قوی‌تر را آزمایش کنند،
- رابط کاربری را ارتقا دهند،
- کنترل خطای داده و Model Drift اضافه کنند،
- و از طریق Pull Request نسخه‌های بعدی Gold4Cast را توسعه دهند.

## مدل فعلی

**مدل اصلی:** XGBoost Quantile  
**Objective:** `reg:quantileerror`  
**ورودی‌ها:** Gold18 + USD/IRR + XAU/USD  
**ساختار ورودی:** ۶۳ lag خام از بازده سه سری  
**افق‌ها:** ۶۳ / ۱۲۶ / ۲۵۲ جلسه معاملاتی  
**خروجی:** Q10 / Q50 / Q90

در نسخه 1.0 هیچ Ensemble یا ترکیب چند مدل استفاده نمی‌شود.

## خلاصه اعتبارسنجی

در بک‌تست پرتراکم از **۱۳۱ مبدأ پیش‌بینی** با فاصله ۲۱ جلسه معاملاتی استفاده شد. چون پنجره‌های پیش‌بینی همپوشانی دارند، برای مقایسه XGBoost با Chronos-2 از تعدیل HAC/Newey-West استفاده شد.

نتایج منتخب XGBoost:

| افق | Pinball | MAPE میانه | پوشش بازه ۸۰٪ | دقت جهت |
|---|---:|---:|---:|---:|
| ۳ ماه | 0.04256 | 12.86٪ | 68.70٪ | 71.76٪ |
| ۶ ماه | 0.07232 | 18.89٪ | 61.83٪ | 83.97٪ |
| ۱۲ ماه | 0.11883 | 29.55٪ | 63.36٪ | 90.08٪ |

کل:

- Average Pinball Loss: **0.07790**
- Average MAPE: **20.43٪**
- Direction Accuracy: **81.93٪**
- XGBoost در **۸۹ مورد از ۱۳۱ مبدأ** loss کمتری داشت.

p-value تعدیل‌شده HAC در مقایسه XGBoost و Chronos-2:

- ۳ ماه: `0.282459`
- ۶ ماه: `0.109399`
- ۱۲ ماه: `0.002677`
- کل: `0.015592`

این نتایج فقط عملکرد تاریخی را نشان می‌دهند و تضمین آینده نیستند. جزئیات در [اعتبارسنجی](docs/VALIDATION_FA.md).

## کارنامه واقعی ربات

هر پیش‌بینی زنده می‌تواند به‌صورت دائمی ذخیره شود. پس از گذشت ۶۳، ۱۲۶ یا ۲۵۲ جلسه معاملاتی، ربات پیش‌بینی قبلی را با قیمت واقعی مقایسه می‌کند و نشان می‌دهد:

- خطای درصدی چقدر بوده،
- جهت رشد یا افت درست تشخیص داده شده یا نه،
- قیمت واقعی داخل بازه Q10 تا Q90 بوده یا نه،
- و آخرین پیش‌بینی‌ها در عمل چقدر به واقعیت نزدیک بوده‌اند.

بنابراین عملکرد مدل فقط با بک‌تست سنجیده نمی‌شود؛ کارنامه واقعی آن نیز به مرور ساخته می‌شود.

## داده

**هیچ دیتاست تاریخی متعلق به سرویس‌های شخص ثالث همراه مخزن عمومی منتشر نمی‌شود.**

کاربر مسئول است داده‌ای را استفاده کند که اجازه قانونی و قراردادی استفاده از آن را دارد. هر Data Provider باید شرایط استفاده، مجوز، rate limit و قوانین مرتبط با منبع داده را رعایت کند.

فرمت پیشنهادی داده:

```text
date,gold18_toman,usd_irr,xau_usd
2026-01-01,...
```

اضافه‌کردن Data Providerهای عمومی و دارای مجوز از طریق Pull Request استقبال می‌شود.

## نصب اولیه

```bash
git clone https://github.com/bdlykhanbary-crypto/gold4cast.git
cd gold4cast
python -m pip install -r requirements.txt
```

سپس مسیر یک CSV مجاز را مشخص و پیش‌بینی را اجرا کنید:

```bash
export GOLD4CAST_DATA=/path/to/market_data.csv
python forecast_xgboost_live.py
```

جزئیات: [ورودی داده](docs/DATA_FA.md).

برای workflow شخصی نگهدارنده در Termux ممکن است دستور زیر فعال باشد:

```bash
gold4cast
```

## استفاده مسئولانه

Gold4Cast ابزار پژوهشی و پیش‌بینی است و **توصیه مالی نیست**. سود یا قیمت مشخصی را تضمین نمی‌کند و «برآورد پایین» نیز کف تضمینی قیمت نیست. شوک ارزی، تغییر سیاست اقتصادی، رویدادهای ژئوپلیتیکی، خطای داده و تغییر ساختار بازار می‌توانند باعث شوند قیمت واقعی خارج از محدوده پیش‌بینی قرار گیرد.
